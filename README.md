# SENTINEL-X

> Enterprise Email Forensics & Threat Intelligence Platform

AI-powered SOC platform for advanced email forensics, threat intelligence, header origin tracing, and attack graph mapping.

## Features

- **Email Analyzer**: 8-stage forensic pipeline analyzing headers, MIME structure, indicators, and payload risks.
- **Header Forensics**: RFC 822 header inspection, SPF / DKIM / DMARC verification, and hop analysis.
- **Origin Investigation**: Sending IP geolocation, ASN infrastructure tracing, and interactive global map visualization.
- **Threat Intelligence**: Indicator correlation, blocklist checks, domain reputation, and campaign clustering.
- **Attack Graph**: Entity relationship mapping between emails, senders, domains, and malware payloads.
- **Reports & Evidence**: Case management, exportable forensic PDF dossiers, and cryptographic SHA-256 evidence vault.
